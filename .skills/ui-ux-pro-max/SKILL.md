# UI/UX Pro Max Skill

## 1. UX Architecture & Information Hierarchy
- **Focal Anchor Discipline**: Every viewport frame has exactly one dominant visual anchor and primary call-to-action.
- **Progressive Disclosure**: Show essential summary context upfront (title, role, outcome metric) and reveal deep case study artifacts on demand via smooth drawers or modals.
- **Claim-to-Proof Adjacency**: Place quantitative metrics, outcomes, and user testimonials immediately adjacent to the capability or project they substantiate.

## 2. Interactive State Completeness
Every interactive component and data view must account for all 5 states:
1. **Default / Resting**: Clean structural hierarchy with clear affordances.
2. **Hover / Focus**: Immediate visual feedback (<150ms) + keyboard-accessible `:focus-visible` outline.
3. **Active / Pressed**: Tactile scale or surface shift confirming user intent.
4. **Loading / Skeleton**: Layout-stable shimmer or progress indicator that prevents cumulative layout shift (CLS).
5. **Empty / Error**: Helpful, human-readable guidance with a direct recovery action.

## 3. Ergonomics & Readability
- **Optimal Line Measure**: Keep body prose between `60ch` and `75ch` with `1.6` line-height.
- **Touch & Pointer Targets**: Minimum `44x44px` hit area on mobile/touch devices; clear cursor affordances on desktop.
- **Contrast & Scrims**: Ensure text over media uses a measured gradient scrim (`from-black/80 via-black/40 to-transparent`) for guaranteed legibility.
